Lista negra de clientes y proveedores ante el SAT

Este módulo proporciona un método para descargar, procesar y guardar en Odoo la lista de contribuyentes bloqueados por el SAT debido a operaciones ilegales con CFDIs, de modo que pueda consultarse cuando sea necesario, con lo anterior, es posible evitar vender o comprar a dichos contribuyentes.

Instalación

Aplicaciones > Partner blocklist > Activar

Forma de Uso

Paso 1

Para descargar la lista en su instancia debe configurar la URL para descargar la Lista Negra publicada por el SAT. Para ésto, visite la página http://omawww.sat.gob.mx/cifras_sat/Paginas/DatosAbiertos/contribuyentes_publicados.html y copie la URL de Definitivos.

Paso 2

Luego, pegue la URL copiada en el campo l10n_mx_partner_blocklist_url dentro de los Parámetros del Sistema.

Paso 3

Actualice la lista negra ejecutando la acción Proceso de Lista Negra de socios.

Paso 4

Cuando se confirma una factura, el RFC del contribuyente es validado en la lista negra, en caso de que el contribuyente esté bloqueado el usuario no podrá confirmar la factura.

Paso 5

Asegúrese de ejecutar la acción “Estado de Lista de Bloqueo del Socio” en el partner para actualizar el status de la lista negra y no permitir la facturación si el contribuyente está bloqueado.

Nota:

Para confirmar la factura a pesar que el contribuyente está bloqueado por el SAT puede eliminar el registro del contribuyente desde el módulo de Contactos, menú Lista Negra de Socios, seleccione el registro y elimínelo desde el botón de acciones (para esto es necesario tener habilitado el permiso de administrador de lista negra de usuarios).
