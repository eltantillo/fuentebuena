About
============
Do you want to simplify your work environment in an organization with access rights? Then this module improves your work efficiency with Instant Access, a powerful tool that simplifies tasks. Customize who can access essential parts of your work, like Menu, Field, Navbar Button, Chatter, Report Action, and Multiaction Views. With a focus on honesty, Instant Access ensures everyone has the right permissions for their work. This access management system simplifies work processes and helps everyone collaborate better.

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.

Features
============
- **Conditional Access Rules**: Restrict Read, Create, Update, and Delete operations based on record-specific domains.
- **Hide Menu**: Hide top-level and sub-menus for specific users/groups.
- **Field Access**: Set fields as Read-only, Required, or Invisible.
- **View Restrictions**: Hide specific view types (Kanban, List, etc.) per model.
- **Chatter Management**: Control visibility of Send Message, Log Note, and Activity.
- **Global Restrictions**: Apply system-wide blocks for Import, Export, Print, and more.
- **Cache Optimization**: Modern cache-busting mechanism for Odoo 19 to ensure immediate permission updates.
